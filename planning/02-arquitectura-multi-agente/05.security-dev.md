## Task S-1 — Security review of POST /internal/usage (P-2)

**Priority:** CRITICAL (block merge until cleared)  
**Triggers when:** platform-dev opens PR for P-2  

### Review checklist

- [ ] `X-Internal-Key` is compared in constant time (or confirm FastAPI/Python `==` is acceptable for this use case — note: `==` on strings is not constant-time, flag as LOW if INTERNAL_API_KEY length > 32 chars making timing attacks impractical)
- [ ] `INTERNAL_API_KEY` is never logged — check all structlog calls in `internal.py`
- [ ] Request body fields have input validation: `ge=0` on integer fields (already in plan — verify implemented)
- [ ] The endpoint does NOT return sensitive data in the 200 response (only `{"status": "ok"}`)
- [ ] SQL: SQLModel parameterized queries used (no raw SQL string formatting with `body.tenant_slug`)
- [ ] Rate limiting: this is an internal endpoint — confirm it does NOT have rate limiting (internal services should not be rate-limited, but verify the limiter middleware doesn't apply globally)
- [ ] Error responses do not leak internal details (stack traces, DB errors)

## Task S-2 — Security review of admin tenants API changes (P-4)

**Priority:** HIGH (block merge until cleared)  
**Triggers when:** platform-dev opens PR for P-4  

### Review checklist

- [ ] `agent_api_key` is encrypted via `encrypt()` before `session.add()` — confirm with `grep encrypt tenants.py`
- [ ] `agent_api_key` does NOT appear in GET response schema or any log output
- [ ] Empty `agent_api_key` on PATCH does not overwrite stored encrypted value

## Risk flags from lead-dev

- **SSRF surface in Sprint 2:** When platform starts calling `agent_endpoint_url`, that URL comes from the DB (tenant-controlled if admin panel is compromised). Flag to security-dev to add URL allowlist validation in Sprint 2 before the external call is implemented.
- **Timing attack on key comparison:** Python `==` on strings is not constant-time. For `INTERNAL_API_KEY`, consider `hmac.compare_digest()`. Flag as LOW for Sprint 1 (internal endpoint, not public-facing).
