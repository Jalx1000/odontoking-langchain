## Risk flags from lead-dev

- **Empty `agent_api_key` on edit:** The backend treats empty string as "no change" (P-4 guard). The form placeholder must make this clear to the operator. Do not remove the existing value from the form field — leave it as empty type="password" (standard behavior for sensitive edit forms).
- **`agent_endpoint_url` in `Tenant` type:** Add as `string` (not `string | null`) — the backend returns `""` (empty string) not `null` when unset. Guard display with `t.agent_endpoint_url &&`.
