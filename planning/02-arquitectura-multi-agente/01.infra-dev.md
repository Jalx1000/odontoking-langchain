## Task I-1 — Add agent_endpoint_url + agent_api_key to Tenant model

**Priority:** high  
**Blocks:** P-1, P-3, P-4, F-1  

### What to do

1. Open `app/models/tenant.py`. After the `agent_type` field, add:
   ```python
   agent_endpoint_url: Optional[str] = Field(default=None, max_length=512)
   agent_api_key: Optional[str] = Field(default=None, max_length=2048)
   ```
   Confirm `Optional` is already imported from `typing` (it is).

2. Generate the Alembic migration:
   ```bash
   make migration MSG="add_agent_endpoint_fields_to_tenants"
   ```

3. Open the generated file in `alembic/versions/`. Verify it contains:
   - `op.add_column('tenants', sa.Column('agent_endpoint_url', sa.String(length=512), nullable=True))`
   - `op.add_column('tenants', sa.Column('agent_api_key', sa.String(length=2048), nullable=True))`
   - Both nullable with no server default (correct for optional fields)

4. Apply the migration:
   ```bash
   make migrate
   ```

5. Confirm with:
   ```bash
   uv run alembic current
   ```

### Deliverable

- [ ] Migration file generated in `alembic/versions/`
- [ ] Migration applied (`alembic current` shows new head)
- [ ] Share the generated revision filename with platform-dev

## Task I-2 — Add INTERNAL_API_KEY to Settings

**Priority:** high  
**Blocks:** P-2  

### What to do

1. Open `app/core/config.py`. Find the `ADMIN_API_KEY` line (around line 172). After it, add:
   ```python
   # Internal API key — used by agent services to call POST /internal/usage
   # Generate: python -c "import secrets; print(secrets.token_urlsafe(32))"
   self.INTERNAL_API_KEY: str = os.getenv("INTERNAL_API_KEY", "")
   ```

2. Open `.env.example` (or `.env.development`). After the `ADMIN_API_KEY` line, add:
   ```

   # python -c "import secrets; print(secrets.token_urlsafe(32))"
   ```

3. Run `uv run ruff check app/core/config.py` to confirm no lint errors.
